# Image Description Toolkit v4.5.1 Release Notes

## What's in this release

**Nothing but the version number.** v4.5.1 is byte-for-byte v4.5.0 apart from the
version stamped into the build.

It exists to exercise the update checker that v4.5 introduced. v4.5.0 was the
first release able to notice a newer version, and the only honest way to prove
that works end to end — GitHub Releases lookup, download, checksum verification,
installer handoff — is to publish something newer for it to find.

If you are running v4.5.0, you should have been offered this update automatically
(or via **Help → Check for Updates...**). That prompt working *is* the thing being
tested.

## Should you install it?

Only if you want to confirm updating works. There are no fixes or features here.
Staying on v4.5.0 costs you nothing.

## Everything else

See the [v4.5.0 release notes](release-notes-v4.5.0.md) for the actual release:
the unified `.idtw` workspace bundle shared by both tools, EXIF + XMP embedding,
GPS context in prompts, and the update checker itself.
