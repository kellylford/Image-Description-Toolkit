# ImageDescriber - AI-Powered Image Description Tool

## 🚀 Quick Start

Welcome! You have everything you need to get started.

### Step 1: Run ImageDescriber (0 minutes)
- Double-click **ImageDescriber.exe** (or ImageDescriber_amd64.exe / ImageDescriber_arm64.exe)
- The app will launch - no installation needed!

### Step 2: Try It Out (Right Now!)
- Load some images
- Create a workspace
- Add descriptions manually
- Export to HTML

**That's it!** The core app works immediately.

---

## 🤖 Want AI Descriptions? (10 minutes setup)

### Option A: Automated Setup (Easiest)
1. Run **setup_imagedescriber.bat** (in this folder)
2. Follow the menu prompts
3. Choose what features to enable

### Option B: Manual Setup
1. Download Ollama from [ollama.ai/download](https://ollama.ai/download)
2. Install Ollama
3. Run: `ollama pull llava:7b`
4. Restart ImageDescriber
5. Done! AI descriptions now work

## ⚡ Three Ways to Use ImageDescriber

### 1. Basic Mode (No Setup Required)
- Launch app → Load images → Add descriptions → Export HTML
- **Perfect for**: Quick manual documentation, organizing photos

### 2. AI Mode (10 min setup)
- Launch app → Select Ollama provider → Let AI describe images → Export HTML
- **Perfect for**: Large collections, consistent descriptions, accessibility

### 3. Cloud Mode (2 min setup)
- Launch app → Select OpenAI or Claude → AI describes images → Export HTML
- **Perfect for**: Highest-quality descriptions, professional work
